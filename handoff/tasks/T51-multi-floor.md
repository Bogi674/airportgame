# T51. Multi floor terminal designer

After MVP 1. Phase 7 of the delivery order approved on 2026-11-10. Status `blocked`: the user has not given the design yet.

## Goal

The player builds terminals on more than one floor, on top of the floor index from T49.

## Known so far

* T49 adds the floor index with only floor 0 buildable. This task lifts that limit.
* T46 (baggage levels, transfers and bridges) depends on it.

## Open questions, all block the task

Ask the user, never invent: the number of floors, how floors connect (stairs, escalators, lifts) with their capacities and costs, which rooms and fixtures are allowed on which floor, how the floor selector and the drawing of other floors work, and how jet bridges and landside access attach to upper floors.
