## The owner's 3 hour session

Play the dev build (`npm run dev`) or the offline file at 4x for three real hours with the browser's performance panel open. Tick each line:

- [ ] Start a career from the new game panel with your own airport name; it shows in the top bar and on the save cards.
- [ ] Build runway, taxiway, apron, stands, a terminal with check in, security, gate desks and a carousel, a depot with roads, a fire station, a staff center and a tower, following the guide card.
- [ ] Sign an airline, place its series in the weekly planner, and watch a full turnaround with vehicles, crew and passengers.
- [ ] Answer at least four events, at least one by letting the fallback apply.
- [ ] Zone a tenant unit, accept a brand, and see rent and sales in the finance sheet the next day.
- [ ] Save as twice, exit, load each card, rename and duplicate one.
- [ ] Frame time stays near 16 ms at 4x with the airport busy; note the worst stall and when it happened.
- [ ] Memory in the performance panel levels off rather than climbing for the whole session.
- [ ] No crash panel, no red error banner, no stand stuck in a turnaround for more than a few game hours without a cause on the flights board.

Report anything that fails with the time, the speed and what was on screen.
