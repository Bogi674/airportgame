# T73 work notes

Decisions (owner, 2026-11-18): bake lazily where the chunk painter runs, cached per asset, tier, rotation, scale and livery. Fixtures without a level draw level 1 of their family; `seating` draws `bench.beam3`, `toilet` draws `washroom.wcStall`.

Implementation decisions (orchestrator):

* The chunk painter runs in the bake worker, so the baker draws on `OffscreenCanvas` and never needs `ImageBitmap`. The planner (`fixturePlan.ts`) is pure and unit tested; the canvas part (`fixtureSprite.ts`) only executes a plan.
* Kit packs load with a dynamic import per category. The bake worker awaits the packs a bake needs before it paints.
* Only fixtures whose kit footprint equals the game footprint are drawn from the kit: checkIn, kiosk, bagDrop, passport, gateDesk, seating, toilet. Security (kit 16 by 4 m, game 2 by 2 m), the legacy belt (carousel 4 by 20 m), shops and the tower keep the old block drawing until T74 and T43 give them the kit footprint. Hard rule 12 forbids scaling the sprite to fit.
* Rotation of a two cell fixture: rot code 1 to 4 (tail toward +x, +y, -x, -y) maps to 0, 90, 180, 270 degrees.

Slices:

1. Pure planner and tests (`src/render/sprites/fixturePlan.ts`).
2. Canvas baker, Path2D cache, gradients, shadow layer, sprite cache, pack loader (`fixtureSprite.ts`, `fixtureKit.ts`).
3. Terminal painter draws the mapped fixtures through the baker, bake worker awaits packs, old block drawing removed for those fixtures.
4. Screenshot check against `docs/art/terminal_scene_kit.png`.
