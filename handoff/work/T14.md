## Decisions (user, 2026-11-11)

* Profile table as proposed by the orchestrator (values in D1).
* One default profile mix for every airline.
* Boarding: the aircraft holds up to 10 game minutes past its turnaround timer, only for cohorts already walking to or queuing at a gate desk. Everyone else misses.

Orchestrator decisions (simplest option, record in ARCHITECTURE section 12 at close):

* Leisure lead is 90 min. Flights carry no domestic or international flag yet.
* Check in opening and closing times, passport, bag drop and patience are not simulated in T14.
* Check in desks and kiosks are equivalent check in points.
* The curb is the lowest id door walk node of the terminal grid.
* A flight uses one terminal grid: eligible grids are those with a curb, a check in point, a security node and a gate desk. Grid = eligible[f % eligible.length]. No eligible grid means no cohorts and zero boarded.
* Aircraft under `TERMINAL_SEAT_THRESHOLD` seats keep the old rule: full passengers, no cohorts.
* Cohorts of a flight are resolved at pushback. This also fixes flight slot reuse.

### D2 store `src/sim/cohorts/cohorts.ts`

```ts
export const enum Stage { Free = 0, Curb = 1, ToCheckIn = 2, CheckIn = 3, ToSecurity = 4, Security = 5, Airside = 6, ToGate = 7, Gate = 8, Boarded = 9, Missed = 10 }
export class Cohorts {
  constructor(rng: Rng, business: Business, traffic: Traffic)   // this.rng = rng.fork('cohorts')
  readonly cap: number                 // PROFILES.capacity
  flight: Int16Array; size: Uint8Array; profile: Uint8Array; stage: Uint8Array;
  node: Int32Array;                    // service node index in the grid's ServiceNodes, -1 none
  timer: Int32Array;                   // wake tick
  bags: Uint8Array; spendBudget: Uint16Array; satisfaction: Uint8Array;
  recipeSeed: Uint32Array; flags: Uint8Array; building: Uint8Array;   // building = grid index
  next: Int32Array;                    // free list link and wheel link
  hi: number;                          // one past the highest slot ever used
  generated: number; boarded: number; missed: number; active: number;   // passengers, not cohorts
  flBoarded: Int32Array; flGate: Int32Array; flActive: Int32Array;      // length MAX_FLIGHTS, passengers
  onScheduled(f: number, tick: number): void
  onPushback(f: number): void
  boardingReady(f: number): boolean    // flGate[f] === 0
  boardedFor(f: number): number        // flBoarded[f]
  update(tick: number): void
  writeSample(views: SnapshotViews): void
  saveState(): CohortsSave; loadState(s: CohortsSave | undefined): void; hash(h: number): number
}
```

Free list: `freeHead` chains recycled slots through `next`; when empty take `hi++` while `hi < cap`. `Boarded` and `Missed` are terminal. A boarded cohort is freed at once. A missed cohort is freed at once unless it sits in a queue (stage CheckIn, Security or Gate): then its stage becomes `Missed` and it is freed when its done event arrives.

Timer wheel: `WHEEL = 4096` buckets, `STEP = 5` ticks. `wheelHead: Int32Array(WHEEL)` filled with -1. `schedule(c, wake)`: `wake = max(wake, tick + STEP)`, `timer[c] = wake`, bucket `Math.ceil(wake / STEP) & (WHEEL - 1)`, push front through `next`. Processing a bucket: detach the whole list first, then for each cohort: `timer[c] > tick` reinserts, otherwise `step(c)`. A cohort is in the wheel only in stages Curb, ToCheckIn, ToSecurity, Airside, ToGate.

### D3 generation `onScheduled(f, tick)`

1. If `flActive[f] > 0` call `onPushback(f)` first (stale slot). Zero `flBoarded[f]`, `flGate[f]`.
2. `if (!business.needsTerminal(f)) return`. `pax = business.paxFor(f)` (both made public).
3. Pick the grid per the decision above. None: return.
4. `dep = traffic.fEta[f] + traffic.fTurn[f]`.
5. While `remaining > 0` and a slot is free: profile by cumulative `mix` against one rng float; `size = min(remaining, rng int 1..maxGroup)`; `lead = leadMin * 600` ticks; `u` = one rng float; `curb = dep - round(lead * (1 + arrivalSpread * (2 * u - 1)))`; fill the slot (`bags = round(size * bagsPerPax)`, `spendBudget = size * spend`, `satisfaction = 100`, `recipeSeed` = one rng 32 bit draw, `flags = 0`, `node = -1`, `stage = Curb`); `schedule(c, curb)`; `generated`, `active`, `flActive[f]` += size.

### D4 journey `update(tick)`

Runs when `tick % 5 === 0`, in this order:

1. Version: if `business.serviceVersion !== seenVersion`: a rebuild keeps queued cohorts whose node survived (node indices may renumber) and lists the rest in `evicted`. For every slot below `hi` in stage ToCheckIn, ToSecurity, Airside or ToGate set `node = -1`. For each grid table and each `k < evictedCount`: cohort `c = evicted[k]`; skip unless `building[c]` is this grid; CheckIn becomes ToCheckIn, Security becomes ToSecurity, Gate becomes ToGate, each with `node = -1` and `schedule(c, tick + STEP)`; Missed is freed; other stages are skipped. Then set that table's `evictedCount = 0` and `seenVersion = business.serviceVersion`. Airside with `node < 0` picks its gate desk from the curb node.
2. Done events, only when `tick % 10 === 0`: for each grid table read `doneCohort[k], doneNode[k]` for `k < doneCount`. Ignore unless the cohort's `building` is this grid and the stage is CheckIn, Security, Gate or Missed. Set `node[c]` to the done node first, since indices can renumber.
   * CheckIn: pick a security node from this node's walk node, stage ToSecurity, schedule the walk. No node: stage ToSecurity, `node = -1`, retry in 100 ticks.
   * Security: stage Airside, `schedule(c, tick + STEP)`. `node` stays the security node.
   * Gate: boarded. `boarded`, `flBoarded[f]` += size; `active`, `flActive[f]`, `flGate[f]` -= size; free.
   * Missed: free.
3. Wheel bucket for this tick. `step(c)`:
   * Curb: pick a check in point (kind checkIn or kiosk) from `business.curbNode(grid)`. Found: stage ToCheckIn, walk. None: retry in 100 ticks.
   * ToCheckIn, ToSecurity, ToGate: if `node < 0` pick again from the curb node and walk (none: retry in 100 ticks). Otherwise `business.serviceJoin(grid, node, c, size)`: true moves to the queue stage and the cohort leaves the wheel; false retries in 50 ticks.
   * Airside: if `traffic.fState[f] === FlState.OnGround` pick a gate desk from the security node's walk node, stage ToGate, `flGate[f] += size`, walk. Otherwise, or with no desk, retry in 100 ticks.

`pickNode(grid, kindA, kindB, fromWalk, c)`: scan the grid's ServiceNodes; candidates have a matching kind and `queueCap > 0`; cost = `walkDistance(grid, fromWalk, walkNode[n]) / walkSpeed + serviceWait(grid, n, tick)`; lowest cost wins, ties to the lowest index; infinite cost is not a candidate. Returns -1 for none. Walk ticks = `max(STEP, ceil(dist / walkSpeed * 10))`.

`onPushback(f)`: for every slot below `hi` with `flight === f` in a live stage (Curb to Gate): `missed += size`, `active -= size`, then free or mark Missed as in D2. Zero `flActive[f]`, `flGate[f]`. `flBoarded[f]` stays until the slot is rescheduled.

Conservation at every tick: `generated === boarded + missed + active`.

### D5 wiring

* `Sim`: `cohorts = new Cohorts(rng, business, traffic)`. `SUBSYSTEMS` gains `'cohorts'` right after `'business'`; it calls `cohorts.update(tick)` every tick. `serialize` adds `cohorts: cohorts.saveState()`, `restore` calls `cohorts.loadState(save.cohorts)` after business and traffic, `stateHash` folds `cohorts.hash`.
* Traffic hooks gain `scheduled?: (f: number) => void` (called at the end of `scheduleArrival` on success) and `boardingReady?: (f: number) => boolean`.
* Sim hook wrapper: `scheduled` calls `cohorts.onScheduled(f, tick)`; `pushback` calls business first, then `cohorts.onPushback(f)`; `boardingReady` calls `cohorts.boardingReady(f)`.
* Boarding hold in `Traffic.updateTurnaround`, new per aircraft `boardHold: Int32Array` (in `arrays()`, reset to 0 at dock):

```ts
if (this.timer[i] > 0) { this.timer[i]--; return; }
if (this.boardHold[i] < BOARD_HOLD_TICKS && this.hooks?.boardingReady && !this.hooks.boardingReady(this.flight[i])) { this.boardHold[i]++; return; }
```

`BOARD_HOLD_TICKS = PROFILES.boardingHoldS * 10`.

* Business: `boarded: ((f: number) => number) | null = null`, set by Sim. `onPushback` for flights that need a terminal: `served = min(pax, boarded ? boarded(f) : 0)`, `lostToday += pax - served`, `satisfaction += (served / max(1, pax) - satisfaction) * 0.1`, `pax = served`. `depCapacity` and `depWindow` are removed everywhere.

### D6 save

`SAVE_VERSION` 13, one bump for the whole task. Business saves service node queue state and `serviceRng` (PITFALLS 27). Cohorts save: counters, `hi`, `freeHead`, every array sliced to `hi` (packTyped), `wheelHead`, the three per flight arrays, rng. `loadState(undefined)` resets to empty. After load `seenVersion = business.serviceVersion`.

### D7 snapshot

`SNAPSHOT_VERSION` 4, `SNAPSHOT_PEOPLE_CAPACITY = 3000`, header `PeopleCount = 4`, views `peopleX`, `peopleY` (Float32), `peopleProfile`, `peopleSize` (Uint8). `writeSample`: stride `max(1, ceil(live / cap))` over slots below `hi`; skip Free, Curb, Missed and `node < 0`; position is the centre of the service node cell in world metres.
