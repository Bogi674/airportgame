## Decisions during the run

* S6: a wall gap into secure floor that only the zone rules close raises both zoneBreach and securityBypass. Two existing business tests expect securityBypass for that gap, and the two issues tell the player different things.
* S6: buildTestTerminal in tests/helpers.ts became a legal zoned layout (lanes rot 1, one security exit in a wall gap, gate desks moved). This pulls S7 DO 7 forward.
* S9: zone issues stay after the early return in terminalIssues. A building without check-in or security is already not ready (noCheckIn, noSecurity), so zone issues on a half built terminal would only add noise; once both exist, zone issues reach readiness through roomIssues.
* S10: the baked zone tint is removed as the brief says, so zones are invisible on the track branch until S11 and S12 add the overlay. The track branch is not merged before S12, so no player build shows the gap. Passport and eGate do not yet draw differently per mode; S15 or a later task may add it.
